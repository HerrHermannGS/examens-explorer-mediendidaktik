# 🎮 Quick Start Guide

## Für Erstnutzer (in 30 Sekunden)

1. **Öffne die App**
   ```bash
   cd ~/Desktop/Coding/Lernanalyse/dist
   open examens_explorer_standalone.html
   ```

2. **Was du siehst:**
   - Oben: Filter-Bar (Suche + Dropdowns)
   - Mitte: Statistik-Karten + Charts
   - Unten: Aufgaben-Cards

3. **Erste Schritte:**

   **Szenario 1: Suche nach "Gamification"**
   - Tippe "Gamification" ins Suchfeld
   - → Sofort werden relevante Aufgaben angezeigt

   **Szenario 2: Nur AFB III Aufgaben**
   - Dropdown "Alle AFB-Level" → "AFB III (Reflexion)"
   - → Nur Aufgaben mit AFB III Operatoren

   **Szenario 3: Alles zu 2022**
   - Dropdown "Alle Semester" → "2022 Frühjahr" oder "2022 Herbst"
   - → Nur Aufgaben aus 2022

   **Szenario 4: Kombiniere Filter**
   - Suche: "CLT"
   - AFB: "AFB II"
   - Semester: "2019 Herbst"
   - → Sehr spezifische Ergebnisse

4. **Aufgabe anschauen:**
   - Klicke auf "▼ Volltext anzeigen"
   - → Kompletter Aufgabentext erscheint

5. **Dark Mode:**
   - Unten rechts: Klicke auf 🌙-Button
   - → App wechselt zu Dark Theme

## Features im Detail

### Filter-Bar
- **Suchfeld**: Volltextsuche über alle Aufgaben
- **Semester-Filter**: 2015-2025
- **AFB-Filter**: AFB I, II, III
- **Themen-Filter**: Alle erkannten Themen
- **Reset-Button**: Setzt alle Filter zurück

### Statistik-Karten
- **Aufgaben gesamt**: Alle 42 Aufgaben
- **Sichtbare Aufgaben**: Nach Filter
- **Semester**: Anzahl der Semester

### Charts
- **Top 10 Themen**: Balkendiagramm
- **AFB-Verteilung**: Kuchendiagramm (AFB I grün, II gelb, III rot)

### Aufgaben-Cards
- **Header**: Semester + Thema-Nummer
- **Operatoren**: Badges mit AFB-Zuordnung
- **Themen-Tags**:
  - 🟢 Grün = Mediendidaktische Konzepte
  - 🟣 Lila = Lehr-Lerntheorien
  - 🔵 Blau = Lernpsychologie
  - 🟡 Gelb = Spezifische Medien
- **Zitate**: Grauer Kasten mit Autor
- **Volltext**: Ausklappbar

## Troubleshooting

**Problem**: Charts werden nicht angezeigt
**Lösung**: Internetverbindung prüfen (Chart.js wird von CDN geladen)

**Problem**: Suche findet nichts
**Lösung**: Reset-Button klicken, dann erneut suchen

**Problem**: Dark Mode bleibt nicht aktiv
**Lösung**: Browser-Cookies/LocalStorage aktivieren

## Pro-Tipps

1. **Kombination ist King**: Nutze mehrere Filter gleichzeitig für präzise Ergebnisse
2. **Statistiken analysieren**: Charts zeigen Trends (welche Themen sind "Evergreens"?)
3. **Volltext durchsuchen**: Suche nach Autorennamen, Theorien, Konzepten
4. **Mobile nutzen**: Perfekt zum schnellen Nachschlagen unterwegs
5. **Teilen**: Schicke die HTML-Datei an Kommilitonen - funktioniert sofort!

## Beispiel-Workflows

### Workflow 1: "Ich will alle CLT-Aufgaben durcharbeiten"
1. Suchfeld: "CLT"
2. → Sehe alle Aufgaben mit Cognitive Load Theory
3. Klicke durch alle Cards, lese Volltext
4. Notiere: In welchen Semestern kam CLT vor?

### Workflow 2: "Was kam 2024 dran?"
1. Semester-Filter: "2024 Frühjahr"
2. → Sehe beide Aufgaben
3. Vergleiche Themen
4. Wechsle zu "2024 Herbst"
5. → Erkenne Pattern

### Workflow 3: "Ich will AFB III üben"
1. AFB-Filter: "AFB III"
2. → Sehe alle Aufgaben mit AFB III Operatoren
3. Fokussiere auf Operatoren wie "diskutieren", "erörtern", "beurteilen"
4. Übe diese Formulierungen

### Workflow 4: "Trends erkennen"
1. Schaue Top 10 Themen Chart
2. → "Lernplattform" kommt 2x vor
3. Suche: "Lernplattform"
4. → Sehe in welchen Jahren (2015, 2019)
5. Vermutung: Könnte 2026 wieder kommen?
